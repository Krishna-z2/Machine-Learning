# 🚗 Car Price Predictor
A Machine Learning web application that predicts the price of used cars based on brand, year, fuel type, and kilometers driven.
This is Based on Car Prediction Dataset that has many Features but main that are need are listed above.

## Tech Stack
Language : Python
Model : Linear Regression
Framework : Flask
Frontend : HTML & CSS(Using Bootstrap)

## How to Run Locally
1. Clone the repo.
2. Navigate to `CarPrediction` folder.
3. Install requirements: `pip install -r requirements.txt`.
4. Run `python app.py`.
